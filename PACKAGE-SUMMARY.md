## 🎨 Customization Quick-Swap

### Change the entire color theme in 3 steps:

1. **Identify your new colors** (use [Color Picker](https://htmlcolorcodes.com/))
   - Background (dark): e.g., `#1a1a2e`
   - Accent secondary: e.g., `#16213e`
   - Accent primary (bright): e.g., `#0f3460`

2. **Replace in all files**:
   ```bash
   # Replace old → new hex codes in README + SVGs
   sed -i 's/0f172a/1a1a2e/g' README.md assets/*.svg
   sed -i 's/134e4a/16213e/g' README.md assets/*.svg
   sed -i 's/14b8a6/0f3460/g' README.md assets/*.svg
   ```

3. **Push and done**!
   ```bash
   git add . && git commit -m "theme: new color palette" && git push
   ```
